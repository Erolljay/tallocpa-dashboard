# AI employees' desks (Claude Cowork)

Each AI employee works at a **desk**: a Claude Cowork project with its own job
description, working procedures (skills), its own TalloCPA OS connector, and scheduled
tasks (docs/AI-WORKFORCE.md §4). The files here are what goes on each desk. The master
data (clients, returns, books) stays in TalloCPA OS; a desk only holds instructions.

| Desk | Files |
|---|---|
| Chief of Staff | [`chief-of-staff/`](chief-of-staff/README.md) |
| Document Clerk | [`document-clerk/`](document-clerk/README.md) |
| Onboarding Officer | [`onboarding-officer/`](onboarding-officer/README.md) |
| Pre-Review Assistant | [`pre-review-assistant/`](pre-review-assistant/README.md) |

More desks come with the AI employees' tools (build step 3 onwards).
